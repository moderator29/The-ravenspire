# The investor deck

`ravenspire-pitch-deck.pptx` is the twelve slide investor deck, generated by
`build-pitch-deck.js` so it can be rebuilt whenever the facts change rather
than hand edited into drift.

## The rule this deck obeys

Every figure on it is real or absent. Rule 4 does not stop at the product
boundary: a deck is the one place a founder is most tempted to round a number
up, and a number invented here is the number a diligence call catches. So the
deck states the round's real terms, the repository's real scale, and no user,
revenue or traction figure at all. Where a fact belongs to the founders rather
than the codebase, the slide carries a bracketed `[Add ...]` marker instead of
a plausible sentence. Fill those in by hand before sending it anywhere.

## Rebuilding

```bash
cd docs/deck
npm install pptxgenjs react-icons react react-dom sharp   # not repo deps
node build-pitch-deck.js
```

The Season Zero numbers on slide nine are duplicated from `lib/season-zero.ts`
by hand, because the generator is plain Node outside the Next build and cannot
import the app's TypeScript. If the round's terms ever change, change them
there first and then here.

## What is on it

Title, problem, insight, the product loop, execution, why now, business model,
moat, Season Zero, the traction plan, the founders, and the roadmap with the
ask. Speaker notes are on every slide.
